# 手柄控制（此 fork）

这是 `purerer/Stronghold-Protocol` 为电脑浏览器增加的输入适配，不属于原作者发布的 v0.3.1。
没有更改联机协议、游戏规则或战斗数值。需要浏览器将手柄识别为 Gamepad API 的 `standard` 映射；
Xbox 和 PlayStation 手柄可通过 USB 或蓝牙连接，具体兼容性取决于系统、驱动和浏览器。

## 开始使用

1. 将手柄连接到电脑，打开游戏，保持标签页在前台。
2. 按一下手柄按键让浏览器识别，再松开所有按键。移动左摇杆，屏幕上出现绿色光标。
3. 在「设置 → 手柄控制」查看检测状态、操作说明，或关闭控制。开关仅影响当前浏览器。
4. 名字和房间码使用键盘输入。开始时用鼠标点击一次页面以解锁声音；全屏等浏览器权限操作也可能需要真实点击。

| Xbox / PlayStation | 操作 |
|---|---|
| 左摇杆 | 移动虚拟光标，中心死区过滤漂移 |
| A / × | 点击；按住移动可拖拽干员、装备；松开落下 |
| B / ○ | 取消当前拖拽，或发送 Esc 关闭界面 |
| 方向键 | 精细移动光标；部署朝向轮盘打开时预览方向 |
| 左摇杆 + A / ×（朝向轮盘） | 预览朝向，然后确认 |
| X / □ | 刷新商店 |
| Y / △ | 购买光标处商品 |
| LB / L1 | 冻结 / 解冻商店 |
| RB / R1 | 升级调度中心 |
| Start / Options | 准备就绪；独立模拟中暂停 / 继续 |
| LT / L2（按住） | 降低光标速度，便于定位小按钮 |
| RT / R2 | 在光标处右键查看详情 |
| 右摇杆 | 滚动光标下可滚动的面板 |

快捷操作沿用「设置 → 快捷键」里的当前键位与现有操作限制：弹窗、观战、托管等不会绕过原来的检查。
撤退、出售使用屏幕上的按钮，未分配到容易误触的摇杆按键。
失焦、切换后台、手柄断开、关闭开关、切回真实鼠标 / 触屏均取消拖拽，不会自动落子；
重新接管时需要先松开所有手柄按键。多个手柄中只使用一个标准手柄，切换时同样需要松键。
普通网页按钮、滑块和面板可以用虚拟光标操作；需要系统权限的操作和文字输入保留实体键鼠。

## HTTPS / localhost

部分浏览器仅在 HTTPS 或 localhost 下开放手柄接口；普通公网 `http://IP:端口/` 可能不支持。
此时设置会提示无法读取手柄。输入适配无法解除浏览器限制，也不会改变服务器的域名备案状态。

在已有 SSH 密钥登录的电脑上，可使用本地转发，不必修改游戏服务的公网端口：

```bash
ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:52301:127.0.0.1:52300 \
  -i ~/.ssh/你的私钥文件 用户名@服务器IP
```

保持该终端打开，浏览器访问 `http://localhost:52301/`。该端口只绑定本机，其他电脑不能通过它访问；
不要把自己的 SSH 私钥交给玩家。其他玩家仍可用原来的地址和鼠标 / 触屏游戏。
面向所有玩家提供手柄时，应为游戏配置浏览器信任的 HTTPS 入口。

参考：[W3C Gamepad API](https://w3c.github.io/gamepad/)、[MDN Gamepad API](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API)。

## 实现与验证范围

入口为 `public/js/ui/gamepad.js`；设置开关持久化到原有的 `sp.pref.settings`，样式位于 `public/css/gamepad.css`。
通过现有 DOM 指针事件、右键、KeyboardEvent 接入，没有发送额外网络消息。
默认按键布局为此 fork 的设计选择 `[ASSUMED]`，不代表官方游戏或上游作者的按键布局。
首版尚未经过实体手柄及跨浏览器验证，需在真实对局中确认拖拽、朝向、面板滚动和断连行为。
